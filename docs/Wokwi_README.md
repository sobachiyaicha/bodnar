# Wokwi: вариант №2 — холодильная камера

## Как открыть
1. Откройте https://wokwi.com/projects/new/arduino-uno в браузере.
2. Вкладка sketch.ino: замените весь текст содержимым нашего sketch.ino.
3. Вкладка diagram.json: замените весь текст содержимым нашего diagram.json.
4. Нажмите зелёную кнопку запуска. Сторонние библиотеки не нужны.
5. В Serial Monitor первая строка появится примерно через 2 секунды.
6. Сохраните проект в своём аккаунте Wokwi и скопируйте его ссылку в README курсовой.

Это локальные файлы для переноса в редактор, а не опубликованный проект Wokwi.

## Состав и подключения
| Компонент | Вывод |
| --- | --- |
| NTC: OUT | A0 |
| LDR: AO | A1 |
| Переключатель: 2 (средний) | D2, INPUT_PULLUP |
| Переключатель: 1 (левый) | GND |
| Переключатель: 3 (правый) | не подключён |
| Зуммер: 2 (+) | D8 |
| Зуммер: 1 (-) | GND |
| Жёлтый LED: анод | D7 через 200 Ом |
| Жёлтый LED: катод | GND |
| NTC и LDR: VCC / GND | 5 V / GND |

Неподключённый DO модуля LDR не нужен: используется аналоговый AO.
Все земли объединены. Влево на переключателе — дверь закрыта (s3=0), вправо — открыта (s3=1).

## Логика
- s1 — температура в °C; рабочий диапазон варианта -30...30 °C.
- s2 — относительная освещённость 0...100 %, НЕ люксы.
- s3 — дверь: 0 закрыта, 1 открыта.
- Период опроса: 2000 мс (2 с); Serial: 9600 бод.
- При s1 > 8 °C включаются звук 1000 Гц и жёлтый LED.
- При s1 <= 8 °C звук и LED выключаются.
- THRESHOLD и NORMAL выдаются один раз при смене состояния.
- Свет и дверь только регистрируются: сами по себе тревогу не включают.
- Гистерезис не добавлен, чтобы сохранить условие задания.

Формат:
```text
DATA n=<номер> s1=<температура> s2=<свет> s3=<дверь>
EVENT n=<номер> type=THRESHOLD
EVENT n=<номер> type=NORMAL
```

## Проверка в Wokwi
1. Начальная температура 4 °C: звук и LED выключены.
2. Нажмите NTC и задайте 12 °C. В ближайшем цикле должны включиться звук и LED,
   а после DATA появиться один EVENT с type=THRESHOLD.
3. Подождите несколько циклов: DATA продолжаются, одинаковый EVENT не повторяется.
4. Задайте 4 °C: звук и LED выключаются, один EVENT с type=NORMAL.
5. Переключите дверь вправо: s3=1; влево: s3=0.
6. Измените lux датчика света: при увеличении света s2 должно расти.
7. Для теста FAULT можно задать NTC 40 °C: значение выйдет за диапазон варианта.
   Сам FAULT создаётся в Node-RED, которого в этом комплекте нет.
8. Скопируйте вывод Serial Monitor в data/log.txt курсового проекта.

Это инструкция для ручной проверки, не утверждение о выполненном запуске в Wokwi.
Код проверен локально с имитацией функций Arduino; это не AVR-компиляция и не симуляция.

## Важный нюанс NTC и методички
В методичке дана учебная линейная шкала:
  -30 + 60 * analogRead(A0) / 1023.
Настоящая модель NTC в Wokwi нелинейна. С этой формулой число в Serial не будет
совпадать с температурой, заданной на датчике, и направление изменения будет другим.
Поэтому ПО УМОЛЧАНИЮ используется beta-формула Wokwi (BETA=3950): температура
в Serial соответствует настройке датчика с погрешностью АЦП.
Источник: https://docs.wokwi.com/parts/wokwi-ntc-temperature-sensor

Если преподаватель требует именно линейное учебное допущение, в sketch.ino
поменяйте USE_METHODICAL_LINEAR_NTC на true. Тогда ориентируйтесь на температуру
s1 в Serial, а не на °C в интерфейсе датчика, и согласуйте это с преподавателем.
Не описывайте beta-формулу в записке как линейную. Для нелинейной NTC температурный
шаг АЦП зависит от температуры; значение 60/1023 относится только к учебной шкале.

Освещённость тоже условная: (1023 - analogRead(A1)) * 100 / 1023.
Резистор LED: (5 - 2.1) / 0.015 = 193.3 Ом, округление вверх до 200 Ом,
расчётный ток около 14.5 мА. Схема EasyEDA должна повторять эти подключения.

## Что менять на защите
- Порог: const float THRESHOLD = 8.0;
- Период: const unsigned long T_MS = 2000;
